\subsection{Vorgehen und verwendete Werzeuge}\label{sec:VerwendeteTools}
Wie schon in \cref{sec:Konzeptauswahl} angewendet, wird auch auch in der Realisierung in die verschiedene Subsysteme unterteilt.
Dies ist hilfreich, da Schnittstellen definiert , Bauteile in Gruppen realisiert werden können und die Komplexität
je Subsystem minimiert wird.

Für die Ausarbeitung werden aus den Teilfunktionen der gewählten Variante konkrete Skizzen erstellt. Diese sollen zunächst eine 
grobe Beschreibung für das Realesystem darstellen. An diesem Punkt kann nochmal gegen Anforderungen und Realisierbarkeit geprüft
werden. Nach diesem Schritt folgt das Erstellen des realen Objektes in einem CAD-Programm. In dieser Arbeit wurde die Studenten 
Lizenz von Autodesk Fusion360 verwendet. Auch elektromechniasche Komponeten werden in diesem Prozess mit eingeplant. Nach der
Erstellung aller Subsysteme am Computer, konnte die einzelnen Bauteile mittels 3d-Druck gefertigt und montiert werden. Für das 
Elektirsche System wurde parallel externe Komponenten zur Steuerung festgelegt und ein Kabelplan erstellt werden. Zur Nachvollziehbarkeit
dieses Schaltplanes wurde eine Schematic in KiCad angefertigt. Nach dem festgelegten Schaltplan wurden dann die einzelnen Komponenten
mit Kabeln und selbst gelegten Leitungen auf einer Lochrasterplatine verbunden. Zur schrittweisen Initialisierung der Anlage wurde 
als Entwicklunghilf des Codes GitHub verwendet. Git ermöglicht es Code schrittweise aufzubauen und einfach zwischen Versionen
zu wechseln. Dieser Prozess wurde weiter durch die Verwendung von DeepSeekV4 unterstützt, der als Co-Worker für das schreiben
und fixen von Code diente.

Diese Aufzählung beschreibt zwar alle verwendeten Werkzeuge, soll aber nicht als zeitliche Darstellung der Realisierung dienen. 
In Realität wurde nach dem Aufbau des einzelnen Subsystems ein Initialisirungstest druchgeführt, der die Grundsätzliche Funktion
überprüfen sollte.
